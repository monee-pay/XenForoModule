# XenForo Module
> Модуль, разработанный для движка XenForo 2.2+, который позволяет создавать счета и осуществлять выдачу цифровых услуг

---
#### Инструкция
##### 1. Установка аддона
- 1.1. Переместите папку "src" в корень вашего сайта (```/```)
- 1.2. Перейдите в вкладку плагинов XenForo и нажмите «Установить» (```/admin.php?add-ons```)  
![image](https://monee.s3.de.io.cloud.ovh.net/docs/img/modules/xenforo/1.jpg)  
##### 2. Настройка аддона
- 2.1. Перейдите на вкладку «Параметры» -> «Платежные профили» и нажмите «Добавить платежный профиль», выберите из списка «Monee»  
![image](https://monee.s3.de.io.cloud.ovh.net/docs/img/modules/xenforo/2.jpg)  
- 2.2. Введите любой заголовок и отображаемое название, а в поле «UUID мерчанта» введите UUID, который можно получить в настройках мерчанта  
![image](https://monee.s3.de.io.cloud.ovh.net/docs/img/modules/xenforo/3.jpg)  
![image](https://monee.s3.de.io.cloud.ovh.net/docs/img/modules/xenforo/4.jpg)  
- 2.3. Выберите аддон в качестве платежной системы во всех местах, где хотите принимать оплату через Monee  
![image](https://monee.s3.de.io.cloud.ovh.net/docs/img/modules/xenforo/5.jpg)
